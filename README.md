# Dog Sitter — сайт компании по выгулу собак

Демо-сайт с **тремя вариантами дизайна** одной компании. Заказчик открывает
ссылку, сравнивает стили, переключается между ними и настраивает сайт под себя
прямо в браузере — без программиста.

> Слоган: **«С заботой о ваших собаках»** · Нижний Новгород · +7 904 049 14 82

## Варианты дизайна

| Вариант | Стиль |
|---|---|
| **Комиксовый** (`variants/comic/`) | Яркий поп-арт: обводки, баблы-реплики, халфтон |
| **Современный** (`variants/modern/`) | Чистый минимализм, мягкие тени, много воздуха |
| **Уютный** (`variants/cozy/`) | Тёплая карамельно-бежевая палитра, серифный шрифт |

Главная страница (`index.html`) — витрина с выбором варианта.
Сверху на каждом варианте есть лента для мгновенного переключения стиля.

## Как настроить сайт (для заказчика, без кода)

1. Откройте любой вариант.
2. Нажмите кнопку-шестерёнку **⚙** справа внизу.
3. Меняйте: название, слоган, телефон, тексты, цвета, ссылки на соцсети;
   включайте/выключайте разделы переключателями.
4. Изменения сразу видны и **сохраняются в вашем браузере**.
5. Кнопка **«Скачать настройки»** сохранит файл — пришлите его разработчику,
   чтобы зафиксировать правки для всех навсегда.

## Как редактировать через код

Весь текст, цены и контакты — в одном файле: **`assets/js/content.js`**.
Он подробно прокомментирован. Меняете там — меняется во всех трёх вариантах.

### Как вставить фотографии

Сейчас вместо фото стоят заглушки с подписью «вставьте фото».

1. Положите фото в папку `assets/img/` (например `dog1.jpg`).
2. В `content.js` впишите путь в поле `img`, например:
   ```js
   hero: { img: "assets/img/dog1.jpg", ... }
   ```
   или ссылку на картинку в интернете. То же самое для услуг и отзывов.

### Фирменный шрифт Comic CAT

Уже подключён в комиксовом варианте (файлы `assets/fonts/ComicCAT.woff2` и `.otf`,
`@font-face` в `variants/comic/style.css`). Автор шрифта — Vitaly Lazarenko,
бесплатен для коммерческого использования.

### Фирменные цвета

Палитра комиксового варианта (из Figma): фон `#FFF6EE`, розовый `#FFD6D1`,
голубой `#CFEDEF`, чёрный текст `#1a1a1a`. Меняются в `:root` файла
`variants/comic/style.css` или мышкой через панель ⚙.

## Публикация на GitHub Pages

1. Создайте репозиторий на GitHub и загрузите туда эти файлы.
2. В репозитории: **Settings → Pages**.
3. **Source**: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
4. Через минуту сайт будет доступен по адресу
   `https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/`.

Файл `.nojekyll` уже добавлен — он нужен, чтобы GitHub Pages отдавал файлы как есть.

## Структура проекта

```
index.html                 витрина с выбором варианта
assets/
  css/base.css             общие стили + панель настроек
  js/content.js            ← ВЕСЬ КОНТЕНТ (тексты, цены, фото)
  js/bind.js               подстановка данных в разметку
  js/customizer.js         панель настроек ⚙ + переключатель вариантов
variants/
  comic/   modern/   cozy/  три варианта (index.html + style.css)
```

Сайт полностью статический (HTML/CSS/JS), без сборки и зависимостей.
