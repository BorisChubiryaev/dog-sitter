Dog Sitter — варианты сайта

С заботой о ваших собаках

Три разных стиля одного сайта. Откройте каждый, сравните и выберите подходящий. На любом варианте есть кнопка-шестерёнка ⚙ — через неё можно прямо в браузере менять тексты, цены, телефон, цвета и прятать разделы. Сверху можно мгновенно переключаться между стилями.

КОМИКС

Комиксовый

Яркий, дружелюбный поп-арт: жирные обводки, баблы-реплики, халфтон. Привлекает внимание, отлично для соцсетей.

Уютный

Уютный

Тёплая карамельно-бежевая палитра, мягкий серифный шрифт, домашняя ламповая атмосфера и забота.

Открыть →

Как настроить под себя: откройте любой вариант → нажмите ⚙ справа внизу. Можно поменять название, слоган, телефон, ссылки на соцсети, цвета и спрятать ненужные разделы. Изменения сохраняются в вашем браузере. Кнопка «Скачать настройки» сохранит файл, который можно прислать разработчику, чтобы зафиксировать правки навсегда.

Фотографии: сейчас стоят заглушки с подписью «вставьте фото». Когда будет папка с фото — их легко подставить (см. файл content.js и README).
